OpenCode Mobile は、自分の PC や Mac で動かしている OpenCode に iPhone・Android からつなぐクライアントアプリです。席を離れていても、エージェントへの指示、進み具合の確認、許可の判断ができます。

できること

  • チャットセッションを選んで指示を送り、返答やツールの実行をリアルタイムで見られます。モデルやエージェントの切り替え、画像の添付、中断もできます。
  • 許可と質問ファイルの編集やコマンドの実行の許可、エージェントからの質問に、その場で答えられます。
  • プッシュ通知応答の完了、エラー、許可待ち、質問を通知します。通知の中身は端末で復号するので、中継サーバーはプロジェクト名やタイトルを読めません。
  • Git・ファイル・ターミナル変更ファイルと差分、ブランチ、ファイルの閲覧と検索、ターミナルまで手元で確認できます。
  • 複数のサーバー自宅の PC と仕事の Mac など、つなぎ先を保存して切り替えられます。
  • データは自分のサーバーとだけチャットやファイルは、アプリとあなたのサーバーの間だけでやり取りします。開発者は受け取りません。

使い方

  1. PC / Mac で OpenCode サーバーを起動する

    OpenCode を最新版にして、パスワードを決めてから、ほかの端末からの接続を受け付けるように起動します。

    OPENCODE_SERVER_PASSWORD=好きなパスワード \
  opencode serve --hostname 0.0.0.0 --port 4096
  2. アプリでサーバーに接続する

    サーバー URL（例: http://192.168.1.10:4096）、ユーザー名（既定は opencode）、パスワードを入れて「接続」を押します。パスワードは端末の Keychain / Keystore に保存します。

  3. プロジェクトとセッションを選ぶ

    OpenCode で開いたことのあるプロジェクトが並びます。セッションを開いて続きを指示するか、新しいセッションを始めます。

  4. 通知を受け取る（任意）

    プロジェクト一覧右上のベルから通知をオンにし、表示される設定を PC の ~/.config/opencode/opencode.json に貼って OpenCode を再起動します。プラグイン opencode-mobile-push は npm から自動で入ります。

外出先からつなぐときは、Tailscale などの VPN を使って、サーバーをインターネットに直接公開しないことをおすすめします。対応しているのは OpenCode v2 の API を持つサーバーです。

料金

無料で使えます。プロジェクトとセッションの一覧にバナー広告が出ます（チャット画面には出しません）。送信が1日10回を超えると、動画広告を見るとさらに10回送れます。買い切りの「広告を外す」を購入すると、どちらの広告も出なくなります。
